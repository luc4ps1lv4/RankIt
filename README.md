# RankIt

O RankIt é uma aplicação web desenvolvida para permitir que usuários criem rankings personalizados, adicionem itens e realizem comparações entre eles para definir uma classificação final.

## Funcionalidades

- Criação de rankings personalizados.
- Cadastro de itens com nome e imagem.
- Comparação entre dois itens.
- Contabilização de vitórias.
- Exibição dos resultados em ordem de classificação.
- Consulta e exclusão de rankings.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Comece a utilizar o RankIt.

Os dados são armazenados localmente no navegador por meio do LocalStorage.
